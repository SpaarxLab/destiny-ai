# Destiny.AI web application

The Next.js application for Destiny.AI. Product authority and team instructions live at the
repository root; read `../PROJECT_STATE.md`, `../DECISIONS.md`, `../SPEC.md`,
`../PLAN.md`, and `../AGENTS.md` before changing application code.

## Local setup

```bash
npm ci
npm run dev
```

## Verification

```bash
npm run check
```

This runs ESLint, TypeScript, and the Next.js production build. It does not prove live WebMCP,
participant usefulness, deployment, or submission readiness.
